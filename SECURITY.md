# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability, please report it by emailing:

**srgnis@srgnis.com**

Please include a short description of the issue and steps to reproduce it.

We will review your report and respond as soon as possible. If the vulnerability is confirmed, we will work on a fix. Please do not publicly disclose the issue until it has been reviewed and addressed.

Thank you for helping keep this project secure.
